Scalable AWS Cloud Infrastructure Deployment

🌠 Project Overview

This project demonstrates the design and deployment of a scalable, secure, and highly available cloud infrastructure using.

The infrastructure was built to simulate a real-world production environment by implementing core AWS networking and compute services, including load balancing and automatic scaling.

The primary objective of this project was to gain hands-on experience with cloud architecture, networking, resource management, and high availability concepts in AWS.

 AWS Services Used
 
💫 Amazon VPC

💫 Amazon EC2

💫 Elastic Load Balancer (ELB)

💫 Auto Scaling Group (ASG)

💫 Security Groups

💫 Public & Private Subnets

💫 Internet Gateway

💫 Route Tables

🏗️ Solution Architecture

The infrastructure was designed with scalability, availability, and secure networking in mind.

Key Architectural Components

✅ Custom Virtual Private Cloud (VPC)

✅ Public and Private Subnet Configuration

✅ Multiple EC2 Instances

✅ Elastic Load Balancer for Traffic Distribution

✅ Auto Scaling for Dynamic Resource Allocation

✅ Secure Access Management Using Security Groups

⚙️ Project Workflow

1️⃣ VPC Configuration

Created a custom Virtual Private Cloud (VPC) to establish an isolated and secure network environment.

2️⃣ Subnet Deployment

Configured public and private subnets across availability zones to improve security and availability.

3️⃣ EC2 Instance Launch

Launched multiple Amazon EC2 instances to simulate application servers.

4️⃣ Security Group Configuration

Implemented inbound and outbound traffic rules for secure communication between resources.

5️⃣ Load Balancer Setup

Configured an Elastic Load Balancer to distribute incoming traffic efficiently across EC2 instances.

6️⃣ Auto Scaling Implementation

Implemented Auto Scaling Groups to automatically adjust infrastructure capacity based on workload demand.
